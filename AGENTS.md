# hubspot-agent-kit

## Agent skills

### Issue tracker

Issues and PRDs live in `tashfeenMustafa/hubspot-agent-kit` GitHub Issues (via `gh` CLI); external PRs are also a triage surface. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical labels, default names: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context layout — `CONTEXT-MAP.md` at root points to per-context `CONTEXT.md` files. See `docs/agents/domain.md`.
