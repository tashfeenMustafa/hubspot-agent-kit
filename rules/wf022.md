# WF-022 — Wrong Internal Action Type ID

**Severity:** HIGH  
**Category:** API Usage  
**API Fixable:** Yes  
**HubSpot Tier Required:** None

## What It Detects
Action uses an internal actionTypeId that doesn't match declared type.

## Why It Matters
workflow executes wrong action silently or fails with obscure error.

## How To Fix
align actionTypeId with the declared action type.

## Detection Logic
actionTypeId/type mismatch against known valid pairs.
