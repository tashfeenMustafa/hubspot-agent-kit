# WF-015 — Convergent Branch Action Tails

**Severity:** HIGH  
**Category:** API Usage  
**API Fixable:** Yes  
**HubSpot Tier Required:** None

## What It Detects
Two or more branches share identical last action (same nextActionId pattern), unsupported by API v4.

## Why It Matters
workflow save fails with 400 error; cannot be updated via API.

## How To Fix
deduplicate tail actions — place shared action after the branch, not in each branch.

## Detection Logic
multiple branches end with identical action signature.
