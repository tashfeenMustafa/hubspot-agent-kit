# WF-038 — GitHub Actions Secret Expiry

**Severity:** MEDIUM  
**Category:** Security  
**API Fixable:** No  
**HubSpot Tier Required:** None

## What It Detects
GitHub Actions workflow using HUBSPOT_API_KEY secret with no rotation reminder or expiry check.

## Why It Matters
automation silently fails when API key is rotated or revoked.

## How To Fix
add key rotation reminder in workflow or use HubSpot OAuth instead of private app key.

## Detection Logic
.github/workflows files using HUBSPOT_API_KEY secret without any expiry/rotation step.
