# WF-028 — UTM Overwrite Conflict

**Severity:** MEDIUM  
**Category:** Data Integrity  
**API Fixable:** Yes  
**HubSpot Tier Required:** None

## What It Detects
Multiple active UTM workflows can enroll the same contact, causing last-writer-wins data corruption.

## Why It Matters
UTM attribution overwritten unpredictably depending on workflow execution order.

## How To Fix
add mutual exclusion suppression filters between UTM workflows.

## Detection Logic
multiple active workflows with utm_source write actions, overlapping enrollment criteria.
