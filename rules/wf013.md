# WF-013 — Re-enrollment On Terminal Workflow

**Severity:** HIGH  
**Category:** Performance  
**API Fixable:** Yes  
**HubSpot Tier Required:** None

## What It Detects
Terminal-state workflow (closed/lost/unsubscribe/disqualified) has re-enrollment enabled.

## Why It Matters
contacts enrolled repeatedly in end-state workflows, duplicate emails, corrupted lifecycle.

## How To Fix
disable re-enrollment on terminal workflows — they should run once.

## Detection Logic
re_enrollment_enabled=True AND name contains closed/lost/unsubscribe/disqualified.
