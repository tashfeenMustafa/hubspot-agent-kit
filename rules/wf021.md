# WF-021 — GOTO Branch Hidden Loop

**Severity:** HIGH  
**Category:** Performance  
**API Fixable:** Yes  
**HubSpot Tier Required:** None

## What It Detects
GOTO action creates hidden loop not visible in workflow UI.

## Why It Matters
contacts stuck in infinite loop, automation quota exhausted, no UI warning.

## How To Fix
remove GOTO actions and replace with explicit branching or separate workflows.

## Detection Logic
action type=GOTO with target pointing to earlier step ID.
