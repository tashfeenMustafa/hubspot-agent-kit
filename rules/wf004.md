# WF-004 — Broken Pipeline Stage Reference

**Severity:** HIGH  
**Category:** Data Integrity  
**API Fixable:** Yes  
**HubSpot Tier Required:** None

## What It Detects
Workflow references a pipeline stage ID no longer in portal.

## Why It Matters
branch logic silently fails.

## How To Fix
update stage reference to a valid stage ID.

## Detection Logic
dealstage field values cross-checked against portal pipeline stages.
