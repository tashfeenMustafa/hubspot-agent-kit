# WF-012 — Missing Workflow Name Prefix

**Severity:** LOW  
**Category:** Governance  
**API Fixable:** Yes  
**HubSpot Tier Required:** None

## What It Detects
Workflow name does not start with a [Category] bracket prefix.

## Why It Matters
bulk filtering and operational audits become harder.

## How To Fix
rename workflow to start with a category prefix e.g. '[UTMs] - My Workflow'.

## Detection Logic
workflow name does not match regex ^\[.+\].
