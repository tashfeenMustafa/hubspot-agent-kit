# WF-034 — Disposition Routing Incomplete

**Severity:** HIGH  
**Category:** Configuration  
**API Fixable:** Yes  
**HubSpot Tier Required:** None

## What It Detects
Call disposition routing workflow missing branches for all possible disposition values.

## Why It Matters
calls with uncovered dispositions fall through with no lead status update.

## How To Fix
add explicit branches for every disposition value used in your portal.

## Detection Logic
PLATFORM_FLOW on calls object with disposition branch logic missing known disposition values.
