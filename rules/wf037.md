# WF-037 — Windows SSL Workaround In Workflow Logic

**Severity:** LOW  
**Category:** Security  
**API Fixable:** No  
**HubSpot Tier Required:** None

## What It Detects
Workflow or supporting script uses verify=False SSL bypass in API calls.

## Why It Matters
security risk — SSL certificate validation disabled, vulnerable to MITM attacks.

## How To Fix
install proper SSL certificates or use certifi bundle; never disable verification in production.

## Detection Logic
script code analysis for requests(..., verify=False).
