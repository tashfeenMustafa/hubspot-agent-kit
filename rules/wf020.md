# WF-020 — Tier-Gated Property Write

**Severity:** MEDIUM  
**Category:** Tier Compliance  
**API Fixable:** Yes  
**HubSpot Tier Required:** Pro+

## What It Detects
Workflow writes to a property that requires a higher HubSpot tier than portal has.

## Why It Matters
write silently fails; feature appears to work but data never updates.

## How To Fix
upgrade portal tier or remove the write action.

## Detection Logic
action writes to tier-gated property AND portal tier < required.
