# WF-030 — Deprecated Filter Operator

**Severity:** HIGH  
**Category:** API Usage  
**API Fixable:** Yes  
**HubSpot Tier Required:** None

## What It Detects
Enrollment criteria uses a filter operator that HubSpot has deprecated.

## Why It Matters
filter silently evaluates as false; enrollment stops working without any error.

## How To Fix
update filter to use current supported operator.

## Detection Logic
filter operators in deprecated set {EQUAL, NOT_EQUAL (old format)} vs current {EQ, NEQ}.
