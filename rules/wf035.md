# WF-035 — CSP Pipeline No Exit Criteria

**Severity:** HIGH  
**Category:** Configuration  
**API Fixable:** Yes  
**HubSpot Tier Required:** None

## What It Detects
Customer Success Pipeline stage workflow has no exit/cleanup criteria for stale deals.

## Why It Matters
deals accumulate in CS pipeline indefinitely; pipeline health metrics unreliable.

## How To Fix
add enrollment criteria or date-based exit logic.

## Detection Logic
workflow targets CS pipeline stages AND has no date-based or activity-based exit filter.
