# WF-016 — Object Type / Flow Type Mismatch

**Severity:** CRITICAL  
**Category:** API Usage  
**API Fixable:** Yes  
**HubSpot Tier Required:** None

## What It Detects
PLATFORM_FLOW with objectTypeId 0-1 (Contacts) returns EXPECTED_PLATFORM_OBJECT_TYPE error.

## Why It Matters
any API save fails with 400; workflow may not run correctly.

## How To Fix
change type to CONTACT_FLOW to match objectTypeId 0-1.

## Detection Logic
type=PLATFORM_FLOW AND object_type_id=0-1.
