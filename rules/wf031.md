# WF-031 — Wrong Pipeline On Deal Creation

**Severity:** HIGH  
**Category:** Data Integrity  
**API Fixable:** Yes  
**HubSpot Tier Required:** None

## What It Detects
CREATE_DEAL action assigns deal to pipeline ID that doesn't exist in portal.

## Why It Matters
deal created with no pipeline, invisible to sales team.

## How To Fix
update pipelineId to a valid portal pipeline ID.

## Detection Logic
CREATE_DEAL action pipelineId not in portal pipelines list.
