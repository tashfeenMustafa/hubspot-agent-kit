# WF-032 — List Filter Branches Array Form

**Severity:** MEDIUM  
**Category:** API Usage  
**API Fixable:** Yes  
**HubSpot Tier Required:** None

## What It Detects
Enrollment criteria uses array-form list filter instead of object form, causing silent mismatch.

## Why It Matters
enrollment criteria evaluates incorrectly; contacts may fail to enroll.

## How To Fix
rewrite list filter criteria in object form per HubSpot API v4 spec.

## Detection Logic
filterBranches contains array-typed listId entries instead of object form.
