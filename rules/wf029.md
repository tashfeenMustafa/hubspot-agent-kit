# WF-029 — Dealstage Write In Deal Flow

**Severity:** MEDIUM  
**Category:** API Usage  
**API Fixable:** Yes  
**HubSpot Tier Required:** None

## What It Detects
CONTACT_FLOW workflow writes dealstage property.

## Why It Matters
silently fails — dealstage cannot be written from contact-based flows.

## How To Fix
use DEAL_FLOW or PLATFORM_FLOW (objectTypeId 0-3) for deal stage updates.

## Detection Logic
type=CONTACT_FLOW AND action writes dealstage.
