# WF-014 — Re-enrollment Off On Normalizer

**Severity:** MEDIUM  
**Category:** Data Quality  
**API Fixable:** Yes  
**HubSpot Tier Required:** None

## What It Detects
Normalizer/backfill workflow has re-enrollment disabled.

## Why It Matters
new contacts matching criteria are never processed, dirty data accumulates.

## How To Fix
enable re-enrollment so contacts are reprocessed when they re-match.

## Detection Logic
FILTER_BASED trigger AND re_enrollment=False AND name contains normalize/standardize/backfill/clean.
