# WF-007 — Write Read-Only Analytics Field

**Severity:** HIGH  
**Category:** Data Integrity  
**API Fixable:** Yes  
**HubSpot Tier Required:** None

## What It Detects
Action writes to hs_analytics_source_data_1/2 which are read-only.

## Why It Matters
write silently fails, attribution data never updated.

## How To Fix
remove the write action; these fields cannot be set by workflows.

## Detection Logic
action field writes include hs_analytics_source, hs_analytics_source_data_1, or hs_analytics_source_data_2.
