# WF-002 — Broken Property Reference

**Severity:** HIGH  
**Category:** Data Integrity  
**API Fixable:** Yes  
**HubSpot Tier Required:** None

## What It Detects
Workflow action writes to a property that doesn't exist in portal.

## Why It Matters
silently writes to nowhere, data never recorded.

## How To Fix
update action to use a valid property or create the missing property.

## Detection Logic
cross-references workflow field writes against portal contact+deal property list.
