# WF-008 — Write OTS From PLATFORM_FLOW

**Severity:** MEDIUM  
**Category:** Data Integrity  
**API Fixable:** Yes  
**HubSpot Tier Required:** None

## What It Detects
Writing hs_analytics_source from PLATFORM_FLOW silently fails.

## Why It Matters
Original Traffic Source is never set, breaking channel attribution.

## How To Fix
use CONTACT_FLOW type for workflows that need to set OTS, or remove the action.

## Detection Logic
workflow.type=PLATFORM_FLOW AND action writes hs_analytics_source.
