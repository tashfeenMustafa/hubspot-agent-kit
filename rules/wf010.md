# WF-010 — UTM Workflow Missing Suppression Gate

**Severity:** MEDIUM  
**Category:** Performance  
**API Fixable:** Yes  
**HubSpot Tier Required:** None

## What It Detects
UTM normalizer lacks suppression filter for already-clean contacts.

## Why It Matters
contacts re-processed on every match, inflated workflow activity.

## How To Fix
add suppression filter checking that UTM fields are not already correct.

## Detection Logic
workflow name contains 'utm' AND suppression_filter_branch is None or empty.
