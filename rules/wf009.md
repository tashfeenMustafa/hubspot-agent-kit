# WF-009 — UTM Convention Violation (Meta)

**Severity:** MEDIUM  
**Category:** Data Quality  
**API Fixable:** Yes  
**HubSpot Tier Required:** None

## What It Detects
Workflow produces non-canonical Meta UTM values.

## Why It Matters
UTM reports show inconsistent source values (facebook/fb/meta mixed).

## How To Fix
standardize utm_source to 'meta' or 'fb' across all Meta workflows.

## Detection Logic
workflow name contains meta/facebook/fb AND utm_source value not in {meta, fb, ig}.
